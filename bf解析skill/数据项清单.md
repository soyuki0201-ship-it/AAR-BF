## 与 v1（原型版）的关键差异（速览）

1. **年龄分段两平台不同**：XHS=`<18 / 18-24 / 25-34 / 35-44 / >44`；DY=`18-23 / 24-30 / 31-40 / 41-50 / 50+`（**无 <18 段**）→"提及单个年龄数字归段"必须按平台执行（如"24占比高"：XHS→18-24 段；DY→24-30 段）
2. **八大人群（仅 DY）实名**：小镇青年 / 都市蓝领 / 新锐白领 / Z世代 / 小镇中老年 / 都市银发 / 资深中产 / 精致妈妈（v1 的"都市白领/小镇中产/都市精英/银发族"**均不存在**）
3. **报价与单价类=父字段+子类型（members）**：DY=植入视频(20-60s)/定制视频(60s+)；XHS=图文/视频。字段实名：`cpuv=外溢进店单价`、`read_cost=阅读成本`、`engage_cost=互动成本`、`cpm=CPM（任一口径）`
4. **平台能力差异**：外溢进店类仅 XHS；CPE/预期播放量/爆文率仅 DY；DY 无"近30天更新视频"开关（XHS 有"近30天更新笔记"）；**组合报价两平台均已不存在**
5. **新增字段**：城市/省份（达人级）、男粉占比、DY 播放中位数、XHS 活跃/下单/阅读/互动粉丝占比、粉丝环比增长率/增长量、合作阅读/互动/外溢进店中位数
6. **预设档位大多取消**：数值字段改纯输入，仅 XHS 合作曝光中位数保留 5 档
7. **系统机制**：`segmentFields=[粉丝数]`、`tierFields`——系统存在粉丝数分层机制，是否可用于分层定价筛选待确认
8. 地域树：国家→省→市三级；兴趣：DY 51 项 / XHS 36 项

## 控件类型 → 判断形态（速查）

| 控件 | 含义 | 可表达判断 |
|---|---|---|
| number | 纯数值输入（含 min/max） | 区间/上限/下限 |
| percent | 百分比数值（0-100） | 占比阈值 |
| select | 单选（枚举） | 等于/属于 |
| multi-select | 多选（枚举） | 包含任一/排除 |
| switch | 开关 | 有/无（布尔） |
| distribution | 分布占比（子项合计100%） | 各子项占比区间 |
| cascading_distribution | 级联分布占比（省市两级） | 省/市占比 |
| cascading_multi | 级联多选（类目树） | 类目包含 |
| region_multi | 地域树多选（国家→省→市） | 地域包含 |
| 父字段+members | 按子类型分别取值（图文/视频、植入/定制） | 子类型化数值区间 |
