## 控件类型 → 可表达的判断形态（速查）

| 类型 | 含义 | 可表达判断 |
|---|---|---|
| range_or_preset | 数值，预设档位+自定义 | 区间（min/max）、档位 |
| distribution | 多子项分布占比（合计 100%） | 各子项占比的区间/排序 |
| gender_rate / region_rate | 性别二项 / 地域分布占比 | 单项占比阈值 |
| checkbox_value | 按子类型分别给数值（图文/视频、植入/定制） | 子类型化的数值区间 |
| cascading_multi / multi_select / single_select | 类目/多选/单选 | 枚举包含 |
| check_toggle | 布尔 | 有/无 |
| combo_quote | 图文（或植入/定制）组合报价 | 组合数值 |
